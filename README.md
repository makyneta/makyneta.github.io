## Sobre

Este repositório contém o código fonte do website pessoal da **Makyneta Unipessoal, Lda.**, uma empresa unipessoal de direito português sediada em Leiria. O site serve como portfolio profissional e ponto de contacto, apresentando os serviços e trabalhos de Tomás Mota em múltiplas disciplinas:

- Desenvolvimento Web Fullstack
- Fotografia de eventos, desporto e retrato
- Design Gráfico e Identidade Visual
- Suporte Informático e Infraestrutura
- Produção de Áudio e Eventos Ao Vivo
- Produção de Vídeo

## Stack Tecnológica

| Camada | Tecnologias |
|--------|-------------|
| **Frontend** | HTML5, CSS3, JavaScript (vanilla) |
| **Framework CSS** | Tailwind CSS (CDN) |
| **Fontes** | Google Fonts (Bebas Neue, Fira Code, Cormorant Garamond) |
| **Ícones** | Font Awesome, Devicon |
| **Hosting** | GitHub Pages |
| **Conteúdo** | Ficheiros JSON para blog, fotos e dados dinâmicos |

## Estrutura do Projeto

```
makyneta.github.io/
├── index.html                # Página principal
├── sobre.html                # Sobre / Portfolio
├── contacto.html             # Contacto
├── design.html               # Portfolio de Design
├── dev.html                  # Portfolio de Desenvolvimento
├── photo.html                # Portfolio de Fotografia
├── video.html                # Portfolio de Vídeo
├── feedback.html             # Feedback
├── 404.html                  # Página de erro
├── robots.txt
├── sitemap.xml
├── assets/
│   ├── styles/               # Folhas de estilo
│   ├── scripts/              # Scripts JavaScript
│   ├── images/               # Imagens e media
│   │   ├── clients/          # Logos de clientes
│   │   ├── profile/          # Foto de perfil e CV
│   │   └── ui/               # Elementos de interface
│   └── data/                 # Ficheiros JSON
├── news/                     # Artigos do blog
├── archive/                  # Conteúdo arquivado
├── info/                     # Páginas informativas
├── legal/                    # Políticas legais
│   ├── privacy-policy.html
│   ├── cookies-policy.html
│   └── terms-of-service.html
└── client/                   # Área de cliente
```
